# Web 前端编程指南

适用范围：所有 Web 前端代码（JavaScript / TypeScript / Vue）。写代码必须严格按本指南执行，违反会被警告。

**1. 运算符**

- `??`（空值合并）：只用于提供默认值。
- `?:`（三元）：只用于简单直接的条件**赋值**；不得嵌套使用；不得用于提供默认值（提供默认值一律用 `??`）。
- `?.`（可选链）：本质是 if 语句的语法糖，检查时在脑中展开成 if 语句再判断，避免滥用；对同一对象多次使用必然导致多次无意义的判断，应合并处理。

**2. 命名**

- 回调函数：`on` + 名词 + 动词过去分词，如 `onHeightChanged`、`onItemRemoved`、`onCreated`。
- 普通变量：小驼峰（`let testA = 1`）。
- 类：大驼峰（`class Test {}`）。
- 常量、枚举：大写下划线（`const THIS_IS_A_CONST = 'test'`）。
- 状态布尔值：`is` 开头——已完成用 `isDownloaded`，进行中用 `isDownloading`，位置用 `isInPanel`。

**3. 赋值与面向对象**

- 创建对象时，尽可能在大括号中完成所有成员初始化。
- 可 get/set 的属性直接使用公有字段（public class fields），不写 getter/setter 包装。

**4. Vue**

- data 初始值尽量用固定类型而非动态类型（空值不应是 `undefined`）：空字符串 `''`、空对象 `null`、空数组 `[]`、`0`、`false`，方便阅读者快速看出属性类型；仅当该类型的空值有实际意义时，才用可变类型 `undefined`。
- 属性改变并向父级传递的事件一律命名为 `change${propertyName}`。

**5. 集合遍历**

- 一律使用 `for..of`，不使用 `forEach`。

**6. 临时变量**

临时变量必须有其存在的意义，否则不创建：

1. 某对象的子对象属性被调用 2 次以上时，为子对象建临时变量。
2. lint 对某段落报错时，用临时变量规避。
3. 只能使用约定俗成的缩写（如 `i`、`idx`），其余一律用全称。

**7. 枚举**

所有状态，除非是透传，必须使用枚举，不得直接使用整数、字符串字面量。

**8. 向量运算**

向量、矩阵运算优先使用对应环境的线性代数库（如 VTK 相关功能用 VTK 的 Math 库），不自己手写。

**9. 注释**

以下情况必须加注释说明：

1. 以 Hack 方式实现功能。
2. 为兼容某一框架而使用特定的变量名称等。
