### Git 提交规则

常驻的只有不可逆边界，工序细节见 `git-commit` skill：

- **只提交，不推送**：一律不执行 `git push` 或其他任何向远端同步的操作（含 force push、PR 创建等）；即使完成任务需要也不要推。涉及远端同步时，提醒用户自行执行即可。
- **不改写已推送的历史**：rebase / reset 重做提交前必须确认这些提交尚未推送到远端；若已推送则禁止改写，只能新增修正提交。
- 执行任何提交相关操作（`git commit`、拆分提交、写提交说明、整理历史）前，先读取 `git-commit` skill 并遵循其中的工序规则，不要凭记忆提交。
